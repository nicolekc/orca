# ralph-context

Project-specific context for developing the Ralph framework.

- `overrides/` — Project-specific additions to `.ralph/` files (mirrors structure)
- `knowledge/` — Accumulated learnings, one file per learning (append-only)
- `prds/` — Task definitions (PRD files)
- `designs/` — Design documents and investigations
- `tasks/` — Durable per-task context (research, brain dumps, design notes, exploration results)
- `project-context/` — Project context directory for Ralph development work (one-shot shape: CLAUDE.md, RESOURCE-INDEX.md, resource categories)
